# Dashboard de Vendas Porsche

## Sobre o projeto

Este projeto consiste em uma dashboard de vendas de carros Porsche, criada para visualizar e analisar os dados de vendas.

## Filtros

- Modelo do carro
- Ano do modelo (Model Year)
- Cidade (City)
- Forma de pagamento (Pay Method)

## Perguntas de negócio

1. Quais são os principais modelos de carros vendidos por cidade?
2. Qual é o ano do modelo mais vendido?
3. Como estão distribuídas as vendas por estado (State)?

## Tecnologias utilizadas

- HTML
- Visualização de dados
